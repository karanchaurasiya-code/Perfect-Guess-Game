# 🎯 Perfect Guess Game (Python)

A fun and interactive number guessing game built in Python. The player tries to guess a randomly generated number within a range, with difficulty levels, a countdown timer, and performance tracking.

## 🚀 Features

- ✅ Easy, Medium, and Hard difficulty levels
- ⏱ Time limit for guessing
- 🎯 Feedback after each guess (Higher/Lower)
- 🔁 Option to play again after each round
- 🧠 Tracks number of attempts
- 🕒 Shows time taken to guess correctly
